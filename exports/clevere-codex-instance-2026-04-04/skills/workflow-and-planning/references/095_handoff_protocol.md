# Handoff Protocol (Codex Skill)

## Purpose
Enable clean transfer across agents/time by standardizing the handoff artifact.

## Minimum Handoff Content
- Objective and current status (FACT)
- Acceptance criteria checklist state
- Files changed and why (paths)
- Verification commands + results
- Open issues / next 1–3 actions
- Any environment quirks (version/fingerprint)

## Where to Record
- Prefer continuity ledger “Current State” + “Verification”
- If no ledger, include a “Handoff” section in the final output

## Failure Conditions
- Next agent cannot proceed without re-deriving basic context
- Missing verification commands or incomplete acceptance state
