# TDD Loop (Preferred)

## Sequence
1) Write/adjust a failing test that captures the bug/desired behavior.
2) Implement the minimal change to pass.
3) Refactor only if needed for clarity, keeping behavior constant.
4) Run targeted tests, then the repo’s standard suite if reasonable.

## When TDD is not practical
- Add a small repro script or a deterministic manual reproduction checklist.
- Still require verification evidence before claiming success.
