# Python Project Conventions

## Structure
- Follow repo structure (src/ layout vs flat).
- Keep imports consistent; avoid reordering unless required.

## Tooling
- Use existing env management (venv, uv, poetry, pip-tools) per repo.
- Respect pinned versions and lockfiles.

## Typing
- Follow repo’s typing stance (no typing / partial / strict).
- Prefer small, local type improvements only when touching the area.
